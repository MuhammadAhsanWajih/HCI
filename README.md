## Tools

- **Figma** for wireframes and prototypes
- **Nielsen's 10 usability heuristics** for evaluation
- **WCAG 2.2** contrast guidance for accessibility checks
- **GitHub** for version control of design work

## HCI design life cycle

1. Understand users and context
2. Specify requirements
3. Design solutions
4. Prototype (low-fidelity, then high-fidelity)
5. Evaluate, then feed the findings back into earlier stages
